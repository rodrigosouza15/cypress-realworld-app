# Cypress E2E Portfolio 🚀

Projeto de testes automatizados E2E usando Cypress + TypeScript,
aplicando boas práticas de QA.

## 🧪 Tecnologias
- Cypress
- TypeScript
- Page Objects
- Fixtures
- Custom Commands

## 📁 Estrutura
- cypress/e2e → cenários de teste
- cypress/fixtures → massa de dados
- cypress/support → comandos customizados

## ▶️ Como executar
yarn install
yarn cypress open
